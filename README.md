# freshjuices

A vibrant, editorial-style healthy juice guide built as a lightweight static web app.

## Highlights
- Fresh visual direction with organic shapes, bold typography and vivid color blocks
- 12 juice blends with ingredient descriptions, nutrient-focused benefits and tags
- Filter by Energy, Glow and Refresh
- Surprise Me interaction
- Responsive layout for desktop and mobile
- No framework or build step required

## Run locally
Open `index.html` in a browser.

## Health note
The benefit copy describes nutrients commonly found in the listed ingredients. It is not medical advice or a treatment claim. Whole fruits and vegetables remain valuable sources of fiber.
