## ✦ What is FreshJuices?

FreshJuices is a **small, polished front-end project** built around one idea: healthy choices should feel exciting.

Instead of presenting a plain list of recipes, the experience uses bold typography, organic shapes, vivid color blocks and lightweight interactions to make each juice feel like its own little character.

## ✨ Features

- **12 colorful juice blends** with ingredients and nutrient-focused benefits
- **Purpose filters** — All, Energy, Glow and Refresh
- **Surprise Me** — jump to a random blend when you don't know what to pick
- **Editorial visual system** — oversized type, organic shapes and bold color cards
- **Responsive design** — built for desktop, tablet and mobile
- **Zero dependencies** — no framework, bundler or build process required
- **Accessible structure** — semantic HTML and straightforward interactions

---

## 🎨 Design direction

FreshJuices deliberately avoids the typical green-and-white “health app” look.

The interface is built around:

**Cream paper** · **Lime energy** · **Coral accents** · **Purple pops** · **Citrus orange** · **Ink-black typography**

The result is meant to feel more like a **modern lifestyle magazine** than a nutrition dashboard.

## 🚀 Run it locally

No installation required.

```bash
git clone https://github.com/mufaddalkt/freshjuices.git
cd freshjuices
```

Then open **`index.html`** in your browser.

That's it.
